Readest Lite 部署教程

1. Docker 快速部署（推荐）

docker run -d \
  --name readest-lite \
  -p 8225:8225 \
  -v readest-data:/data \
  -e ADMIN_EMAIL=admin@example.com \
  -e ADMIN_PASSWORD=changeme \
  -e SUPER_ADMIN_EMAIL=admin@example.com \
  --restart unless-stopped \
  ghcr.io/cshdotcom/readest-lite:latest
💡 提示：设 SUPER_ADMIN_EMAIL 与 ADMIN_EMAIL 相同即可获得超级管理员角色（可创建/管理 admin），重启容器后自动生效。

2. Docker Compose 部署

2.1 创建 .env 文件

ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=changeme
SUPER_ADMIN_EMAIL=admin@example.com
PORT=8225

2.2 docker-compose.yml

services:
  readest-lite:
    image: ghcr.io/cshdotcom/readest-lite:latest
    container_name: readest-lite
    restart: unless-stopped
    ports:
      - "${PORT:-8225}:8225"
    volumes:
      - ./data:/data
    env_file:
      - .env

2.3 启动

docker compose up -d

3. 环境变量

变量必填默认说明
ADMIN_EMAIL✅—管理员邮箱
ADMIN_PASSWORD✅—管理员密码
SUPER_ADMIN_EMAIL可选—设为与 ADMIN_EMAIL 相同的值即可获得 super_admin 角色
ADMIN_USERNAME可选—管理员显示名
ADMIN_AVATAR_URL可选—管理员头像 URL
PORT可选8225监听端口
JWT_SECRET可选派生值JWT 签名密钥
PUBLIC_BASE_URL可选—反向代理场景下必填（如 https://read.yourdomain.com）
RECYCLE_BIN_EXPIRE_DAYS可选30回收站过期天数
DEEPL_ENABLED可选false启用 DeepL 翻译
AI_GATEWAY_API_KEY可选—AI 聊天网关

4. 反向代理（Nginx）

server {
    listen 443 ssl;
    server_name read.yourdomain.com;

    # SSL 证书
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:8225;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 文件上传大小限制
        client_max_body_size 100m;
    }
}
⚠️ 重要：反向代理场景下必须设置 PUBLIC_BASE_URL 环境变量为你的外部域名（如 https://read.yourdomain.com），否则签名 URL 会指向 localhost 导致上传/下载失败。

5. 升级

docker pull ghcr.io/cshdotcom/readest-lite:latest
docker compose down && docker compose up -d
💡 升级后：浏览器硬刷新（Ctrl+Shift+R）清掉旧的 Service Worker 缓存。

6. 数据备份

所有数据存储在 /data 目录：

data/
├── db/             SQLite 数据库
├── books/          书籍文件
├── avatars/        用户头像
├── inbox/          Send to Readest 入站文件
└── config.json     运行时配置

备份只需复制整个 data/ 目录即可。
